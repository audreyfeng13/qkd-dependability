## Real bugs fixed (not cosmetic — these affect correctness or performance)

### 1. `qne/cascade/sdc_runs.py` — slow Toeplitz path
Was calling `injector.toeplitz_extract_with_fault()` (the `to_matrix()`-based
method, empirically ~70-120+ seconds per call at real-scale output lengths)
instead of `injector.fast_toeplitz_extract_with_fault()` (the fast,
`ext.extract()`-based equivalent, <1 second). This is the single biggest
blocker to scaling up trial counts — every synthetic/Mock sweep using this
function was paying this cost unnecessarily. **Fixed: now uses the fast path.**

Also added an optional `out_len` parameter to `run_sdc_experiment()`, so
callers can pass a finite-key-corrected length instead of always falling
back to the placeholder `relative_source_entropy=0.5` formula.

### 2. `qne/cascade/sweep_utils.py` — broken real-channel filename handling
`run_real_channel_trial()` and `run_real_channel_reconciliation_trial()` read
from the literal, passed-in `--output` filename — but `bob_cascade_driver.py`
always auto-suffixes the real output path with fault parameters and a
timestamp (to prevent silent overwrites across sweeps). These functions were
therefore reading a file that was never created under that exact name.
**Fixed: now parses the real filename from stdout via `extract_output_path()`**,
matching the working pattern developed live in `13_mitigation.ipynb`.

### 3. `scripts/bob_cascade_driver.py` / `scripts/alice_cascade_responder.py` —
   inconsistent PA output length between Alice and Bob
Both scripts independently computed the PA output length from the same
formula and inputs — fragile, given today's session hit multiple real
key-length mismatches between Alice's and Bob's data. **Fixed: Bob now
computes `out_len` once and transmits it explicitly in the `pa_seed` message;
Alice uses the received value instead of recomputing it independently.**
This removes an entire class of potential Alice/Bob disagreement.

Also added `--use-finite-key-length` flag to `bob_cascade_driver.py`, and
switched both scripts' Toeplitz calls to the fast path.
